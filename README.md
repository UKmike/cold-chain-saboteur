# ColdChain Saboteur

A real-time (with pause & speed controls) reverse supply-chain strategy game. An AI **Seafood Importer/Broker** works to keep global shipments flowing into its **Cold-Storage Buffer** to fulfill **End-Buyer** contracts, while you play as a **Disruptor** triggering strikes, spoilage, customs holds, and demand surges to force stockouts or bankrupt the broker.

## Running Locally

```bash
npm install
npm run dev
```

## Running Tests & Build

```bash
npm test
npm run build
```
